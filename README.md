# Projektseite der Dissertation von J. Franz Th. Meißner

Quarto-Website, veröffentlicht unter <https://jfthm.github.io/pro/>.

- Bauen: `quarto render` (Ausgabe in `docs/`, von GitHub Pages ausgeliefert)
- Erscheinungsbild: `assets/theme.scss` (Farben, CSS-Variablen), `assets/fonts.css` (lokale Schriften)
- Exposé-Versionen: `daten/expose_versionen.csv`, PDFs in `dokumente/`
- Kernliteratur: Zotero-Tag `R_Kernliteratur` setzen, dann `Rscript R/kernliteratur.R`
- Alte Seiten und Skripte: `_archiv/` (werden nicht gerendert)
